Car Rental Management System

A Java-based Car Rental Management System developed using Object-Oriented Programming (OOP).

Project Overview

This application helps manage car rentals, customers, bookings, and vehicle returns through a graphical user interface.

Technologies Used

- Java
- Java Swing
- MySQL / MariaDB
- XAMPP
- JDBC
- NetBeans IDE

Key Features

- User Login and Registration
- Car Management
- Car Booking and Rental
- Customer Management
- Return Car Management
- Database Connectivity

Database

MySQL/MariaDB database managed through phpMyAdmin using XAMPP.
